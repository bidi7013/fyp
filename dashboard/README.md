# ASPIRE-Vision Dashboard (React + Tailwind CSS)

Scheduled for development in **Week 3 (Target: Monday, 9 November 2026)**.

## Objectives
* Offline client-side visualizer capable of reading local CSV output files and playing recorded video.
* Explicitly separates regional occupancy (density inside a drawn polygon) from directional line-crossings.
* Synchronizes video playback timestamps with the exported event log table.

## Planned Stack
* **Vite + React (TypeScript)**
* **Tailwind CSS**
* **Lucide React** (icons)
* **Recharts / Chart.js** (temporal density curves)
* **PapaParse** (fast client-side CSV parsing)
